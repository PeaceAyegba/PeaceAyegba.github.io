# Personal Website

Source code for my personal website, built with Astro and hosted on GitHub Pages.

**Website:** https://peaceayegba.github.io/

The website is where I share my research, personal projects, and learning.

## Built With

- Astro
- HTML and CSS
- Markdown for blog posts
- GitHub Pages

## Local Development

```bash
npm install
npm run dev
```

## Deployment

The website is automatically deployed to GitHub Pages using GitHub Actions when changes are pushed to the `main` branch.
